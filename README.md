# RIX 资源块提取工具

这是一个用于从游戏资源包中“特异性提取 `.rix` 文件”的小工具。  
它会扫描二进制文件，定位符合特征的资源块，并按块导出为独立的 `.rix` 文件。

## 1. .rix 文件特征

该工具识别的 `.rix` 文件格式具有以下特征：

- 文件头：`AA 55`
  - 十六进制表示：`0xAA 0x55`
- 文件尾：`80`
  - 十六进制表示：`0x80`

也就是说，程序会寻找：

- 以 `AA 55` 开头的数据块
- 以 `80` 结尾的块
- 并且该 `80` 后面要么紧跟下一个 `AA 55` 头部，要么它就是文件中的最后一个有效块

这类数据块通常被保存在游戏包中，作为音频或资源文件的一部分。

---

## 2. 工具原理

脚本的核心逻辑如下：

1. 读取输入文件中的所有二进制数据
2. 从文件中扫描 `AA 55` 头标识
3. 在当前头之后继续寻找 `80` 结束标识
4. 判断哪些 `80` 是有效结束位置：
   - 如果某个 `80` 后面紧跟 `AA 55`，则说明这是一个块尾
   - 如果没有符合条件的 `80`，则使用最后一个 `80` 作为该块的尾部
5. 提取从头到尾的完整二进制数据块
6. 将块保存为：
   - `原文件名1.rix`
   - `原文件名2.rix`
   - `原文件名3.rix`
   - 以此类推

输出文件名从 `1` 开始编号，例子如下：

```bash
game.bin
game1.rix
game2.rix
game3.rix

---

## 3. 使用方法

命令行用法：

```bash
python cut.py <文件名>
```

例如：

```bash
python cut.py package.dat
```

执行后，程序会自动扫描 `package.dat`，提取所有符合条件的 `.rix` 块，并输出到当前目录。

如果文件不存在，会输出错误提示；如果没有找到符合条件的数据块，也会给出提示。

## 6. 包文件说明

本工具的使用范围仅限于：

- 仅查找 `music` 相关的资源包
- 仅对 `.rix` 文件进行特异性提取
- 不做大规模全包扫描或无差别解包

也就是说，程序的目标不是“提取整个文件”，而是“从特定游戏资源包中精确提取音乐相关的 `.rix` 数据块”。

这使得它适合以下场景：

- 资源包中混有大量非 `.rix` 数据
- 需要保留高特异性筛选
- 只提取音乐资源，不污染其他文件内容

## 8. 注意事项

- 该脚本依赖二进制数据结构，适用于已知资源包格式的游戏文件
- 若资源包并非 `music` 相关，或不是 `AA 55` + `80` 的块结构，则可能无法识别
- 提取结果会保存到当前目录，建议在单独目录中运行

其识别条件简单明确：
