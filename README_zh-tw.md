# RIX 資源區塊擷取工具

這是一個用於從遊戲資源包中「特異性擷取 `.rix` 檔案」的小工具。  
它會掃描二進位檔案，定位符合特徵的資源區塊，並將每個資料塊依序匯出成獨立的 `.rix` 檔案。

## 1. `.rix` 檔案特徵

此工具所辨識的 `.rix` 檔案格式具有以下特徵：

- 檔案頭：`AA 55`
  - 十六進位表示：`0xAA 0x55`
- 檔案尾：`80`
  - 十六進位表示：`0x80`

也就是說，程式會尋找以下型態的資料塊：

- 以 `AA 55` 開頭的資料區塊
- 以 `80` 結尾的資料區塊
- 且該 `80` 後面要麼緊接下一個 `AA 55` 區塊標頭，要麼就是檔案中的最後一個有效區塊

這類資料塊通常會被嵌入在遊戲資源包中，作為音樂或其他資源檔案的一部分。

---

## 2. 工具原理

這個腳本的核心邏輯如下：

1. 讀取輸入檔案中的所有二進位資料
2. 從檔案中掃描 `AA 55` 區塊標頭
3. 在目前標頭之後繼續尋找 `80` 結束標記
4. 判斷哪些 `80` 是有效的結束位置：
   - 如果某個 `80` 後面緊接另一個 `AA 55`，則代表這是目前區塊的結尾
   - 如果沒有符合條件的下一個標頭，則取最後一個 `80` 作為區塊結尾
5. 擷取從開頭到結尾的完整資料區塊
6. 將每個區塊另存新檔為獨立的 `.rix` 檔案
7. 輸出檔名從 `1` 開始依序編號

例如：

```bash
game.bin
game1.rix
game2.rix
game3.rix
```

---

## 3. 使用方法

命令列用法如下：

```bash
python cut.py <檔案名稱>
```

例如：

```bash
python cut.py package.dat
```

執行後，程式會自動掃描 `package.dat`，擷取所有符合條件的 `.rix` 區塊，並匯出到目前目錄。

如果檔案不存在，程式會輸出錯誤訊息；如果沒有找到符合條件的資料塊，也會提示使用者。

---

## 4. 程式說明

主要的入口函式在：

```python
if __name__ == "__main__":
    main()
```

它會接收命令列參數，並呼叫：

```python
extract_blocks(input_file)
```

這個函式會：

- 讀取二進位內容
- 找出有效的區塊邊界
- 擷取每個區塊
- 將區塊寫入磁碟
- 顯示每個區塊的偏移位置與長度資訊

程式執行時，會輸出類似以下資訊：

- 區塊編號
- 匯出檔案名稱
- 起始與結束偏移
- 區塊長度
- 前 16 個位元組的十六進位預覽

這有助於確認擷取出的資料塊是否符合預期格式。

## 6. 包檔案說明

此工具的用途僅限於：

- 只搜尋 `music` 相關的資源包
- 只對 `.rix` 檔案做特異性擷取
- 不做大規模全包掃描或無差別解包

換句話說，這個工具的目標不是「擷取整個檔案」，而是「從特定遊戲的資源包中精準擷取音樂相關的 `.rix` 資料塊」。

這種方式適合以下情境：

- 資源包中混雜大量非 `.rix` 資料
- 只需要保留音樂相關資源
- 需要高特異性篩選，而不是整體解壓

## 8. 注意事項

- 這個腳本依賴已知的二進位結構規則，適用於已知資源包格式的遊戲檔案
- 若資源包不是 `music` 相關，或不符合 `AA 55` + `80` 的資料塊格式，則可能無法辨識
- 擷取結果會儲存到目前工作目錄，建議在單獨資料夾中執行

## 9. 結論

這個腳本本質上是一個「結構化二進位區塊擷取器」，用來從遊戲資源包中辨識並輸出 `.rix` 音樂／資源區塊。  
其辨識條件非常明確：

- 檔頭：`AA 55`
- 檔尾：`80`

它適合用於特定老牌遊戲資源包中的 `.rix` 擷取工作，特別是音樂相關資源的提取。
